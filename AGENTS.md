# AGENTS.md — First-read contract for every model

1. READ `HANDOVER.md` in full before any coding, claiming progress, or restructuring. Then `README.md` and `knowledge/AGENTS.md`.
2. Respect the stable research taxonomy **AI-01 through AI-07**. The priority is context-aware **AI-01 action semantics / character intention**, with physical AI-02 foundational interaction and the gated portal benchmark.
3. Current authority: canonical `knowledge/` V8, root `HANDOVER.md`, `BACKUP_MANIFEST.md`. Historical ZIPs/V2–V7 are evidence and provenance, not active overrides.
4. Every scenario: provide **context → character/audience knowledge → intention → perception → anticipation → visible action/contact → reaction/consequence → camera → sound → code → proof**. Distinguish physical motion, camera motion and time remapping.
5. Be skeptical. **L1** sourced, **L2** designed, **L3** code executed, **L4** rendered and inspected, **L5** passes production QA and regression. A valid file does not establish compelling motion or causal story.
6. Existing 90 presets are **drafts**, 42 action recipes and 3 bad/good tests are **research prototypes**. No 270-frame complete portal benchmark is approved. Do not invent missing media or claim test passes.
7. Before work: `python knowledge/08_TOOLS/audit_repo.py`, search existing presets, read STATUS and open evidence gaps. If verification cannot run, report the limitation.
8. After work: update learning log, source ledger, access gaps, defect cases, decision and conflict log, session log, handover, and backup manifest with exact file paths and hashes where relevant. Never erase failed experiments.
9. **Repair loop**: OBSERVE → DEFINE expected result → IDENTIFY root cause → CHANGE one hypothesis → RENDER → INSPECT consecutive frames + listen → TEST regression → LOG. After two nonworking fixes, reconsider architecture.
10. GitHub writes: confirm target repo / branch / permissions; prefer one auditable batch commit; verify HEAD and retrieve files afterward. Preserve old snapshots. Never commit credentials or assets without redistribution rights.
11. On context loss: re-read `HANDOVER.md` and `knowledge/00_START_HERE/RECOVERY.md`, inspect present files and latest commit, identify last verified milestone and unresolved defects, then continue. Do not force the user to search old chat.
