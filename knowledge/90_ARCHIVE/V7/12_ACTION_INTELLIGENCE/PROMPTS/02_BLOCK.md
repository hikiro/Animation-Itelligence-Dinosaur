# Module 02 — Build an event-addressable storyboard

**Input:** approved interpretation + world map + actors/props.

Define end-exclusive frame ranges, key poses and onsets, screen direction, gaze targets, contact coordinates, object ownership changes, rig requirements and camera coverage. Include a continuity state at each edit. Produce a low-detail blocking animatic before polished assets. Do not skip unresolved physically necessary interaction stages. Identify how you would prove real physical contact and when time/style is exaggerated.
