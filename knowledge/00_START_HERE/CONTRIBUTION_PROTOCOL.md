# Standard operating procedure for new lessons and presets

## Source/lesson lifecycle
1. Create research note with permanent ID, original URL/location, inspection date, creator and licensing/reproduction considerations.
2. Write verbatim **small** observation (avoid copying large copyrighted material), then interpretation in a separate section.
3. Link observation to scenario/event and context (actor, goal, audience, style, anatomy, scale, setting, camera and acoustic environment).
4. Assign evidence level independently to each claim.
5. Build preset with required fields and exception/size variants.
6. Implement narrow experiment, inspect frames/audio, log defect and results; don't overwrite synthetic hypothesis with "real".
7. Update indexes and `LEARNING_LOG.md` with what changed and what remains unknown.
8. Run auditor and rebuild search index before handoff.

## Search protocol
Stable IDs never change. Use domain prefixes: SRC, LRN, PRE, EXP, DEF, GAP, DEC, CONFLICT. Link exact local paths. Include subject, action, emotion, material, creature, scale, camera, audio and status tags to retrieve cross-topic lessons.

## Promotion rule
L2 → L3 requires code execution logs. L3 → L4 requires inspectable media and review notes. L4 → L5 requires written, context-appropriate acceptance tests, a regression run and independent review when feasible.
