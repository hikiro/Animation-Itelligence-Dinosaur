# Original editable four-style dinosaur project

Original user-provided archive dated November 2026. Because the 9,327,572-byte GitHub transfer exceeded a connection-size limit, the ZIP is stored here as **ten exact binary parts** and can be reconstructed byte-for-byte.

From the repository root:

```bash
python tools/reassemble_original.py
```

Output: `DINO_FOUR_STYLES_EDITABLE_PROJECT.zip`.

Expected SHA256: `48cfd510a01155bbfa7d6e40380957e3258b9895f56c1d53fe10a77127216b0e`.

The script checks the part count, file length, SHA256 and ZIP CRC before reporting success.

**Content:** Original project's 4 five-second clips, 20-second compilation, `motion.js`, `render.py`, `sound.py`, `finalize.py`, scene HTML and QA contact sheet. It is the **flawed first prototype**. Do not confuse it with the approved nine-second portal benchmark, which remains unfinished.
