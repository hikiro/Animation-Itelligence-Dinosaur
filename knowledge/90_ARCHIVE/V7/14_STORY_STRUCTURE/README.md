# Story-structure reference library (NEW in V7)

This library stores **user-provided storytelling frameworks, the context in which they help, and counterexamples**. It is NOT a universal formula for all animated work. Treat a screenshot as evidence of what the screenshot shows, not of the accuracy or effectiveness of the advice in the unseen original video.

- `REF-STORY-0001.md` — user-provided short-form structure (screenshot, eight ordered beats)
- `REFERENCES/REF-STORY-0001_shortform_stacked_beats_user_upload.png` — exact uploaded reference; internal study use only, do not claim a license for external redistribution
- `CONTEXT_ADAPTATION_AND_TESTS.md` — retention versus character acting, context selection, payoff tracking
- `STORY_STRUCTURE_RECORD_SCHEMA.json` — fields required for future references

**Search:** `python 08_TOOLS/search_knowledge.py "open loop" --scope 14_STORY_STRUCTURE`; `python 08_TOOLS/search_materials.py --query short-form`.

**Status:** visual observation from user-uploaded screenshot verified; origin/video/audio not independently inspected; predictive retention benefit not audience-tested. Do not equate "looks like a retention framework" with measured performance.
