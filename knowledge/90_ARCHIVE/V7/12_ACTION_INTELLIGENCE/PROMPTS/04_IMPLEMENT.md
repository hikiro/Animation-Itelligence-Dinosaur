# Module 04 — Implement animation and physical interaction

**Input:** storyboard state, rig, precise frame events, camera/audio sheets.

Implement primary character/root/IK poses first. Build masks, ownership transfer and collision response as explicit state. Use After Effects properties and expressions, or deterministic Remotion/JS controllers, as appropriate; do not misdescribe AE expressions as project-authoring scripts. Prefer pure frame functions and deterministic randomness. Provide actual code, runnable commands and a reference/bad baseline. Render representative frames including contact boundaries. Log missing modules rather than pretending they exist.
