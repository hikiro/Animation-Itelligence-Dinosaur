# Multi-gate animation QA and rejection criteria

G0 **provenance**: source, authorship, rights, observation vs synthesis and contextual caveats logged.
G1 **semantic**: scene intention and causal event graph internally coherent.
G2 **rig/contact**: supports, joint limits, scale, collisions, prop attachment and depth ordering credible.
G3 **motion**: timing/spacing, anticipation, body mechanics, momentum and acting consistent.
G4 **camera/edit**: geography, screen direction, silhouettes, eye-trace, motivated moves and transitions.
G5 **audio**: events tied to contact, source space/material, dynamics and dialogue/narrative priority.
G6 **technical**: encoded media integrity, frame count, reproducibility, asset and licensing checks.
G7 **comprehension/regression**: silent, visual-only, audio-only and independent viewer evidence when available.

**Fail immediately:** portal not crossed despite script; feet visibly slide in planted phase; object magically attaches; reaction before stimulus absent justified reflex; camera hides key action; sound announces impact that never occurs.

**Review method:** for each failed check record exact frame/time, expected, observed, suspected root cause, test, repair, retest artifact hash and reviewer. Mark as unverified if visual evidence unavailable. Technical checks never imply G7 success.
