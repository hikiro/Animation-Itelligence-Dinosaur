# PROMPT 05 — Editorial rhythm, continuity and color progression

## Copy into agent

> Act as film editor and color/continuity supervisor. Read locked scene geography, script, shot cards and `01_RESEARCH/01_VISUAL_CAMERA_DIRECTION.md`. Build a timeline where cuts have a narrative cause and screen direction remains consistent. Track outgoing/incoming eye location, action phase, actor positions, egg/portal state and sound bed across every edit. Avoid cutting away before a critical catch, threshold crossing or release. Plan visual setup, development, pause and payoff for each scene. Create eight scene-level colorscript plates showing how value, warmth/coolness, accent contrast and lighting change with emotion, without inventing inconsistent light sources. Define sound bridges early: offscreen mother footfalls before reveal, lingering debris after branch, portal ambience across forest/apartment. Run a silent animatic and re-time if any cause is too fast to perceive. Do not fix an unclear story with captions or arbitrary jump cuts.

## Deliverables

Edit decision list/shot timeline, colorscript descriptions or plates, continuity report, eye-trace map and reason for each cut. Save latest timecode/frame boundaries in canonical script/cue table. Reject if there is no proof of action completion or if the audience cannot reconstruct geography on first viewing.
