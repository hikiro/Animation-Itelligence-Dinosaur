# LRN-0008 — A living learning log requires evidence classes and search

## Claim and scope
Research statements, observed issues, proposed fixes and verified repairs have different evidence requirements. Learning must be searchable and preserved with versioning.

## Plain-language instruction → technical implementation
Stable IDs, local search script, append-only log, notes with URLs/timecodes/conditions, cross-links, explicit uncertainty and regressed defects.

## Where not to overapply / alternative interpretations
An editorial hypothesis can still be useful but must never be described as verified.

## Observable acceptance test
Query by natural-language synonyms and stable ID, inspect exact paths, run file/manifest audits.

## Typical failure
Agent invents that the revised animation passed without looking at media.

## Evidence status and dependencies
**production-heuristic**; refer to source IDs in `01_RESEARCH/00_SOURCE_LEDGER.md` and directly related lessons. These are reusable principles, not claims of a tested and corrected V4 video. All AE snippets remain runtime-unverified.
