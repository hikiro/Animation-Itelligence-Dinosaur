# LRN-0009 — Translate impact as an event graph, not one effect

## Claim and scope
The human request “make it obvious that a projectile hits” expands into launcher pose/recoil, visible travel/geography, actual collision, receiving-body response and aftermath.

## Plain-language instruction → technical implementation
Write a director contract including all stages, choose style and shot coverage, encode event timing and layers, then QA with effects/audio off and on.

## Where not to overapply / alternative interpretations
Some shots intentionally conceal travel or impact; replace literal travel with alternate trustworthy cause-effect evidence, not a contradiction.

## Observable acceptance test
Silent-viewer causal order and whole-body contact QA; frame before/on/after impact; context-matched audio.

## Typical failure
Bullet is flashy and fast but receiver falls before it arrives.
