# Minimal session checklist to prevent drift

Every new session:

- [ ] Locate the actual extracted kit and the active production project separately.
- [ ] Read README/AGENTS/STATUS and open defects; verify last artifact paths.
- [ ] Verify source claims before making them; do not use past conversation narrative as file evidence.
- [ ] Announce current phase, one deliverable, success test and known blocker.
- [ ] Read context coupling and one relevant modular production prompt.
- [ ] Lock current actor/object/world/audio state before writing/animating.
- [ ] Render a small diagnostic rather than the full film if core physics/portal state is uncertain.
- [ ] Independently review muted picture, contact frames, sound POV and exported media.
- [ ] Mark only real evidence as VERIFIED; otherwise show UNVERIFIED/BLOCKED.
- [ ] Record defects, repair, regress, update status and handoff.

## During every scene

- Ask what the **actor wants**, what the **audience knows**, what **physical event** must happen, why the **camera** is placed there, and what **sound** helps tell it.
- Do not add movement merely to make the scene more energetic.
- Keep one primary attention channel and at most two supports unless motivated otherwise.
- Never cut or blur away decisive physical contact.

## At end of session

Record: current stage, exact file versions, tested commands, actual frame/audio evidence, defects still open, next single action. If user asks “is it done?” answer based on artifacts, not effort.
